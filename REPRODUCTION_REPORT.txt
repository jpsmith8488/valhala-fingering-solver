the fixes are deep-copies before mutation. The frozen solver itself was
never modified.

    exponent for any demo run afterward (1.49 clean -> 1.24 after

    tradition object in place, shifting the Russian scaling exponent
    (1.71 -> 1.72) if the battery was run before the figures in the
    same session.

the captions, which quote raw ARI) and a 1-based "Note position in
passage" axis, consistent with the manuscript.
