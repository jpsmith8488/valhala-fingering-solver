# Reviewer reproduction guide

This file is for reviewers of the manuscript

> *Optimal Piano Fingering from a Physically Parameterized Variational
> Framework with Inverse Parameter Recovery*

It maps every numerical claim and every figure in the paper to the
command that regenerates it from the frozen solver.

## One-command verification

```bash
pip install -r requirements.txt
bash verify_all.sh
```

`verify_all.sh` runs `reproduce_paper.py`, `verify_figures_tables.py`,
`validation_battery.py`, and the two figure-generation scripts in order,
and exits 0 only if every check passes. Expected total runtime is under
two minutes on a current laptop. The frozen solver and all of the
verification scripts depend only on NumPy; Matplotlib is needed only for
the figure scripts.

## Frozen solver

Every numerical result in the manuscript was produced by

```
valhala_solver_standalone.py
MD5: 846ce6aae16623c6ca4a551f86df869c
```

This file is not edited between paper revisions. The same MD5 must hold
for the reproducibility claims below. To verify:

```bash
md5sum valhala_solver_standalone.py     # Linux
md5 valhala_solver_standalone.py        # macOS
```

## Numerical tolerances

`reproduce_paper.py` uses tight tolerances that match the precision of
the paper's printed values: integer matches for fingerings, ±0.05 for
peak ARI values (paper reports one decimal), ±0.01 for action values
(paper reports two decimals), and ±0.01 for scaling exponents (paper
reports two decimals ±SE). The Baroque–Modern μ_c comparison allows ±0.15
because the value depends on the granularity of the metric-weight sweep
in the figure script (the underlying solver result is deterministic).

## What is *not* in this package

- Score files (the test passages are encoded as MIDI-note lists inside
  the solver, not as separate score files).
- The manuscript itself.
- Any data files (no measurements were collected; everything is computational).

## Reporting an irreproducibility

If a number in the paper does not match what the scripts above produce,
please note the exact discrepancy (your figure vs. the paper's) and
include the output of

```bash
python --version
python -c "import numpy; print(numpy.__version__)"
md5sum valhala_solver_standalone.py
```

so the author can identify the source.
